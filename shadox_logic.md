Shadow Logic — Full Explanation

The shadow logic is a self-supervised illumination invariance mechanism that helps the model learn to segment objects correctly regardless of whether they're in sunlight or shadow. It has three interconnected parts:

────────────────────────────────────────────────────────────────────────────────

Part 1: Synthetic Shadow Injection (Data Augmentation)

File:  pointonlysam/fixed_data.py ,  _shadow()  function (line 23)

During training, the data pipeline creates two views of each image:
- Weak view: slightly brightness-jittered, clean image
- Strong view: the same image with a randomly generated synthetic cast shadow overlaid

The synthetic shadow is generated by:
1. Creating a small (16×16) random noise grid
2. Gaussian-blurring it to make it smooth
3. Upscaling to full resolution with cubic interpolation — producing a spatially varying light attenuation field
4. Multiplying pixel values by  (1.0 - attenuation)  to darken regions, simulating a cast shadow

The shadow strength ranges from 0.10 to 0.52 (10%–52% darkening). It's applied with probability  shadow_probability  (default 60–75%).

The fixed model also produces a shadow mask — a soft confidence map derived from the attenuation field (line 68):

// python
shadow_mask = np.clip((attenuation - 0.08) / 0.32, 0, 1)

This thresholded attenuation map tells the model where the synthetic shadow is strongest (only regions with >8% attenuation are included).

────────────────────────────────────────────────────────────────────────────────

Part 2: Shadow-Invariant RGB Encoder

File:  pointonlysam/fixed_model.py ,  ShadowInvariantRGB  class (line 55)

Instead of feeding raw RGB directly to the semantic decoder, the model uses illumination-normalized cues:
1. Chromaticity (3 channels):  R/(R+G+B) ,  G/(R+G+B) ,  B/(R+G+B)  — color ratios are invariant to uniform darkening
2. Local-mean normalized color (3 channels): pixel value / local average (15×15 pool) — cancels out spatially smooth illumination changes
3. Gradient magnitudes (2 channels): horizontal and vertical edges — shadows don't destroy edges

These 8 channels are processed through a CNN stem, producing 48 feature channels. A shadow head (1×1 conv) on top predicts a per-pixel shadow probability.

────────────────────────────────────────────────────────────────────────────────

Part 3: Shadow Gating in the Decoder

File:  pointonlysam/fixed_model.py ,  FixedSemanticDecoder.forward()  (line 110)

The decoder fuses SAM features with the appearance branch:

// python
shadow_prob = shadow_logits.sigmoid()
gated_app = app * (1.0 - 0.65 * shadow_prob)

Where the shadow head predicts strong shadow, the appearance branch contribution is attenuated by up to 65%. This forces the model to rely more on SAM's geometry features (which are illumination-invariant since SAM was pretrained on diverse lighting) in shadowed regions.

During inference,  shadow_prob  is detached (no gradients), so the shadow head acts as a fixed gating mechanism.

────────────────────────────────────────────────────────────────────────────────

Part 4: Shadow Disentanglement Loss

File:  pointonlysam/fixed_objectives.py ,  shadow_disentanglement_loss()  (line 225)

This is the core training signal. It enforces that the student (strong/shadowed view) should agree with the teacher (weak/clean view) specifically in shadow regions:
1. Compute KL divergence between student and teacher logits at every pixel
2. Weight by the  shadow_mask  — only shadow regions contribute
3. Optionally weight by teacher confidence — low-confidence teacher predictions are downweighted with a soft floor of 0.25 (never fully zeroed)

// python
weight = shadow_mask * (0.25 + 0.75 * teacher_confidence)
loss = (KL * weight).sum() / weight.sum()

This teaches the model: "Even though the image is darkened in these regions, your prediction should still match what you'd predict on the clean image."

────────────────────────────────────────────────────────────────────────────────

Part 5: Shadow Head Supervision

File:  pointonlysam/fixed_objectives.py ,  shadow_mask_bce()  (line 272)

A simple binary cross-entropy loss supervises the shadow head to predict which pixels are shadowed:

// python
loss = BCE(shadow_logits, shadow_mask)

This gives the gating mechanism a direct learning signal about illumination changes.

How It All Fits Together

Training Image
    │
    ├──→ Weak view (clean)  ──→ Teacher encoder ──→ Teacher logits (frozen EMA)
    │
    └──→ Strong view (+ synthetic shadow)  ──→ Student encoder
              │
              ├──→ SAM features (frozen, illumination-invariant)
              │
              └──→ ShadowInvariantRGB (chromaticity + local contrast + gradients)
                        │
                        ├──→ Shadow head → shadow_prob (gates appearance contribution)
                        │
                        └──→ Gated appearance features
                                  │
                                  └──→ Fused with SAM features → Student logits
                                                                    │
                                          Shadow disentanglement loss ◄──┘
                                          (student ≈ teacher in shadow regions)

Why This Matters

In remote sensing (satellite/aerial imagery), shadows from buildings, clouds, and terrain are extremely common. Without shadow invariance, the model would:
- Misclassify shadowed vegetation as water or asphalt
- Fragment object boundaries at shadow edges
- Learn spurious correlations between darkness and certain classes

The shadow logic makes the model robust to illumination changes without requiring any shadow annotations — it's entirely self-supervised through the synthetic shadow augmentation and teacher-student consistency.
