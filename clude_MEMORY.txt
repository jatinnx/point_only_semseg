3. THE PRISM LOSS (what to defend in the paper)
================================================================================
Curriculum by INFORMATION SOURCE: human-derived -> image-derived ->
frozen-geometry -> model-derived LAST.

human-derived
  L_point  CosFace additive angular margin at clicked pixels
  L_prop   CE on point->region propagation, label-smoothed INSIDE S with a
           MEASURED eps (not tuned). Conflict regions excluded everywhere.
  L_abs    THE CENTRAL TERM. Partial-label / candidate-set max likelihood:
             -log( eta + (1-eta) * sum_{c in S} p_c )
           Removes C-|S| degrees of freedom at ALL 65536 pixels. With leak eta>0
           the loss is bounded by -log(eta) and the gradient by (1-eta)/eta, so
           an image where a class was never clicked contributes bounded penalty
           instead of being punished for being right. -> kills mode 2 structurally.
  L_pres   MIL top-k coverage. SEE SECTION 4 — this was changed this session.
  L_area   one-sided area floor from propagation, gamma=0.60. GT never violates it.
  L_phead  ADDED 2026-09-02. The inventory as a PREDICTION TARGET, not only as a
           constraint. 1x1 stack on the decoder trunk -> LSE-pooled over space at
           T=0.5 -> 17 logits -> multi-label BCE against S(I), pos_weight 4.1146
           (MEASURED: mean |S(I)| = 3.3238 over 630 images). Minimiser sigma(z_c)=1
           for c in S(I), else 0. WHY IT EXISTS: every other inventory term dies at
           inference because a test image has no clicks, and 10.52% of val pixels
           are a class the image's own inventory excludes. This is the only
           inventory mechanism that survives to test time. LSE not mean pooling: a
           40px class is 0.06% of a mean, so mean pooling learns only big classes,
           and the hallucinated classes are precisely the small ones.
           Applied at inference as a SOFT prior, never a hard mask:
             logit_c += lambda * log(sigma(z_c)*(1-delta) + delta),  delta=0.05
           so a wrong "absent" costs log(0.05) ~ -3.0 instead of deleting a class
           from an image that contains it. lambda=0 (default) is the identity.

image-derived
  L_potts  edge-aware Potts / dense-CRF pairwise, as a TRAINING loss
  L_bnd    ONE-SIDED boundary precision: penalise predicted discontinuity only
           where no contour is allowed. One-sided on purpose — a two-sided term
           rewards drawing contours, and under 0% supervision the cheapest way to
           earn that is to over-segment.
  L_sh     shadow equivariance (dichromatic model, log-average luminance
           invariance theorem)
  L_shead  asymmetric shadow-head BCE (negatives at weight 0.3; clean view pushed
           to 0 ONLY inside the synthesised blob, so the head learns contrast and
           not "dark implies shadow")

frozen-geometry
  L_hom    region homogeneity by SHARPENED SELF-DISTILLATION, t_R ~ (region mean
           projected onto S)^(1/tau), stop-grad.
           KEY PROOF: under the coupled iteration the uniform distribution is a
           STRICT REPELLER with multiplier 1/tau > 1; one-hots are the attractors.
           This is exactly why it is NOT written as within-region JS/divergence
           minimisation — for D_R = H(mean p) - mean H(p) >= 0, EVERY constant
           assignment is a global minimum with value 0, a whole degenerate
           manifold including uniform. JS kept only as an ablation row.

model-derived, LAST (epoch 8+)
  L_self   hard region pseudo-labels through 5 filters in this order: project
           onto S -> average per region -> drop tiny/conflict/already-clicked ->
           adaptive tau = mu - kappa*sigma over an EMA of region confidences plus
           a top-2 margin -> emit HARD labels.
           KEY PROOF (bounded target family): the set of targets L_self can EVER
           present is finite and DOES NOT GROW WITH TRAINING STEPS, because the
           partition R comes from pretrained SAM before step 1 and never changes.
           E3's target family was the whole simplex at every pixel and moved with
           the network. THIS is the structural reason degradation should stop.
           Hard not soft, because Gibbs caps the student at max_c t_c.
  L_anc    prototypes pulled to an EMA of ANNOTATED-pixel features only
  L_rep    within-class prototype repulsion (stops K collapsing to 1)

Anti-confirmation-bias mechanism, stated plainly: the SAM region partition is
class-agnostic, computed ONCE by grid-prompt AMG, cached, and FROZEN. Nothing the
network predicts can change it.

    THE BUG: k was a constant, max(64, 0.005*65536) = 327. Every present class
    was required to produce 327 confident pixels. A class that truly covers 40px
    can only satisfy that by OVER-CLAIMING ~8x. That pressure falls hardest on
    exactly the rare classes the method exists to rescue (ship, court, tanks,
    mobile home) and surfaces as failure mode 5 charged to the NEIGHBOUR's pixels.
    Root cause: k was doing two jobs. Its only legitimate job is gradient
    stability (k=1 is max-pooling, unstable at batch 1). Area estimation is
    L_area's job and L_area does it from a bound GT provably satisfies.

    THE FIX: k_c = clip(|P_c|, k_min=64, k_max=327), where |P_c| is the same
    propagated pixel count L_area constrains against.
      - large class: cap binds, k_c = 327, behaviour unchanged
      - 40px class: k_c = 64, the stability floor, nothing more
      - class with no propagated region (click fell in a conflict region):
        |P_c| = 0 -> k_c = 64. Correct default: the inventory still asserts the
        class exists, and nothing has been measured about its size.
    Since k_c <= k_max always, this ONLY EVER RELAXES the term. Anti-flooding is
    untouched — flooding is blocked by L_abs and L_area, never by this ceiling.
    |P_c| is read off integer labels so k_c carries no gradient.
    Comparison pinned to fp32 with an int64 arange: in vals.dtype a bf16
    autocast would round 327 -> 328.
    New ablation row `const-k-present` (pres_const_k=True) makes the claim
    testable. READ THAT ROW ON RARE-CLASS IoU AND BOUNDARY PRECISION, NOT mIoU —
    the classes it should hurt contribute least to the mean.
